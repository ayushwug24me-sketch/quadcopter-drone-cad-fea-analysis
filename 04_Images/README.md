# Image Organization

The report screenshots are divided by engineering purpose and renamed descriptively.

- `01_CAD_Assembly` — final assembly, part-model views, and mass properties
- `02_ANSYS_Setup` — material/mesh and loading/boundary-condition setup
- `03_Static_Structural` — deformation, stress, strain, and additional static result view
- `04_Modal` — modes 1–4
- `05_Harmonic_Response` — frequency-response and resonance views

The filenames describe the content rather than the original PDF page/image numbering, making the repository easier to navigate on GitHub.
