# ANSYS Workbench

The supplied Workbench archive is preserved unchanged. Based on the extracted archive structure inspected for this project, the three systems are organized as follows:

- `01_Static_Structural/` — `dp0/SYS/MECH`
- `02_Modal/` — `dp0/SYS-1/MECH`
- `03_Harmonic_Response/` — `dp0/SYS-2/MECH`
- `04_Workbench_Archive/archive_DRONE.wbpz` — original Workbench archive

The original archive should not be manually renamed internally. If the project is reopened in ANSYS Workbench, the three systems may be displayed with the descriptive names **Static Structural**, **Modal Analysis**, and **Harmonic Response**.

The large solver result files remain inside the Workbench archive rather than being duplicated into the repository folders.
