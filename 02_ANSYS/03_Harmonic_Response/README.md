# ANSYS Harmonic Response Analysis

This package extracts the Harmonic Response section of the supplied engineering report.

## Source pages
Pages 14–15 of the complete engineering report.

## Analysis setup
- Method: Mode Superposition
- Frequency spacing: Linear
- Frequency range: 1–150 Hz
- Intervals: 150
- Excitation: 32 N per arm, +Z
- Four harmonic forces at the motor mounting locations

## Reported response
- Harmonic peak: approximately 90 Hz
- Peak normal-stress amplitude: approximately 0.0151 MPa
- Peak deformation amplitude: approximately 0.186 mm
- Modal frequencies near the peak: 89.963 Hz and 89.971 Hz

## Included evidence
- Harmonic normal-stress amplitude/phase versus frequency
- Harmonic deformation amplitude/phase versus frequency
- Resonance summary around 90 Hz
- Original report pages 14–15

The report recommends comparing the final motor/propeller operating frequencies and harmonics against the simulated modal frequencies.
