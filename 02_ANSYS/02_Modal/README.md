# ANSYS Modal Analysis

This package extracts the Modal Analysis portion of the supplied engineering report.

## Source pages
Pages 12–13 of the complete engineering report.

## Modal model
- Structural geometry and fixed support retained.
- Detailed motor/propeller geometry replaced by four point masses.
- Point mass at each motor location: 0.105 kg.
- Six natural frequencies extracted.
